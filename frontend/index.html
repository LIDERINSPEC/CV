Guia de Deploy — Passo a Passo
1. Backend (Railway)
• Acesse railway.app → New Project → Deploy from GitHub
• Suba a pasta /backend do projeto
• Em Variables, adicione: ANTHROPIC_API_KEY=sua_chave
• Railway detecta o Procfile e sobe automaticamente
• Copie a URL gerada e cole acima em "URL do Backend"

2. Frontend (Vercel)
• Acesse vercel.com → New Project → Import do GitHub
• Suba o arquivo index.html da pasta /frontend
• Em Environment Variables, adicione: VITE_API_URL=url_do_railway
• Deploy automático em ~1 minuto

3. Chave da Anthropic
• Acesse console.anthropic.com
• API Keys → Create Key → copie e cole no Railway
